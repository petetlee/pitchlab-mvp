# Workflow: /pitchlab_scaffold

Scaffold the PitchLab MVP codebase or verify existing structure.

Default stack:
- Flutter (Frontend)
- Firebase (Firestore, Auth, Functions)
- Google Genkit (AI Orchestration)
- Vertex AI (LLM)
- Playwright (Web testing) or Flutter Integration Tests

Routes:
- `/` (Home/Landing)
- `/new` (New Evaluation Form)
- `/e/[id]` (Evaluation Result)
- `/history` (Evaluation History)

Provide setup instructions and proof after scaffold (e.g., `flutter run` screens or Firebase emulator status).
