# Workflow: /pitchlab_export_pdf

Add Export to PDF for PitchLab evaluations.

PDF must include:
- Idea summary
- Q1–Q7 table
- Scores (PitchLab Score & Risk Score)
- TEAR sections
- Next steps (Action Plan)

Implementation Options:
- Flutter: use `pdf` and `printing` packages.
- Backend: use a Cloud Function with `pdfkit` or similar.

Must work locally and provide proof of generated file.
