# Workflow: /pitchlab_missions

Mission Prompts (Run in Order) to build PitchLab MVP:

1. **Mission 1** – Run `/pitchlab_spec`: Define the blueprint.
2. **Mission 2** – Run `/pitchlab_scaffold`: Set up the Flutter/Firebase structure.
3. **Mission 3** – Run `/pitchlab_scoring_engine`: Build the core logic.
4. **Mission 4** – Run `/pitchlab_tear_writer`: Integrate AI generation.
5. **Mission 5** – Add history + sharing: Firestore integration and navigation.
6. **Mission 6** – Run `/pitchlab_export_pdf`: Enable reporting.
7. **Mission 7** – Run `/pitchlab_review_release`: Final polish and deploy.
